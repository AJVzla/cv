Preguntas frecuentes

¿Qué es AMPscript?

Es el lenguaje de scripting de Salesforce Marketing Cloud. Sirve para personalizar emails, SMS y CloudPages con los datos de cada contacto.

¿Qué es una CloudPage?

Es una página web alojada dentro de Marketing Cloud que puede leer y guardar datos en Data Extensions. Se usa para formularios de registro, centros de preferencias y landing pages de campañas.

¿Podés sumarte a un equipo que ya usa Marketing Cloud?

Sí, es como trabajo hoy: dentro de equipos internacionales, a partir de requerimientos funcionales y técnicos, con Jira y GitHub.
